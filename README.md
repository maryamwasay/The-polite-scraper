# Polite Scraper

## Overview

Polite Scraper is a Python-based web scraping project developed as part of the Backend AI Engineering workshop. The scraper collects book information from a practice website, extracts useful data, cleans and structures it, and saves it into CSV and JSON formats.

The project follows responsible web scraping practices by respecting robots.txt, identifying itself with a custom User-Agent, and introducing delays between requests to avoid overwhelming the server.

The structured data generated by this scraper can be used as a dataset for Retrieval-Augmented Generation (RAG) applications in future AI projects.

---

# Project Goal

Build a scraper that:

- Fetches pages from a practice website
- Extracts useful information
- Cleans and structures the extracted data
- Saves records into CSV and JSON formats
- Behaves like a polite and responsible web scraper

---

# Features

- Fetches web pages using the Requests library
- Parses HTML using BeautifulSoup
- Extracts structured book information
- Cleans extracted data
- Saves output as CSV
- Saves output as JSON
- Uses a custom User-Agent
- Respects rate limiting
- Checks robots.txt before scraping
- Maintains modular project structure
- Generates structured data suitable for AI/RAG pipelines

# Workflow

The scraper follows a structured data processing pipeline.

```
Fetch
   ↓
Parse
   ↓
Extract
   ↓
Clean
   ↓
Structure
   ↓
Save
```

### Step 1 — Fetch

Downloads the HTML content of the webpage while using a custom User-Agent.

### Step 2 — Parse

Converts the HTML into a BeautifulSoup object for navigation.

### Step 3 — Extract

Extracts the required information from the webpage.

Extracted fields include:

- Title
- Price
- Rating
- Availability
- Product URL

### Step 4 — Clean

Removes unwanted symbols, whitespace, and formatting from the extracted data.

### Step 5 — Structure

Converts cleaned information into Python dictionaries.

### Step 6 — Save

Stores the final dataset in:

- CSV format
- JSON format

# Ethical Web Scraping

This project follows responsible scraping practices.

## robots.txt

The target website's robots.txt file was checked before scraping to ensure that scraping was allowed.

---

## User-Agent

The scraper identifies itself using a custom User-Agent instead of making anonymous requests.

Example:

```
PoliteScraper/1.0 (Educational Project)
```

---

## Rate Limiting

To avoid sending too many requests in a short period, the scraper pauses between requests using:

```python
time.sleep(2)
```
